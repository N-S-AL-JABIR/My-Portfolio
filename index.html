01 About

Where software meets hardware

I'm an Electrical & Electronic Engineering graduate from Manarat International University. I write Python, C/C++ and JavaScript, build web back-ends with Django and Django REST Framework, and bring those skills into embedded systems, robotics and IoT work.

My projects range from an ESP32 biometric attendance system with a web dashboard, built for a company, to a PID-controlled line-following robot and a robo soccer robot that I take to inter-university competitions.

Alongside engineering, I've solved 700+ competitive programming problems, judged robotics and science competitions, and helped found the IEEE Student Branch at my university.
